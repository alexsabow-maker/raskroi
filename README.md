Сайт «🧲 Раскрой листа металла» — это калькулятор для оптимизации раскроя листового металла. Он помогает разложить нужные детали на листе так, чтобы отходов было меньше, и посчитать, сколько листов покупать.

Что он делает по содержанию страницы:

Задаёте размер листа (в мм) — например, стандартный 1000×2000 мм.

Добавляете детали — прямоугольные заготовки с размерами и количеством (в примере на странице: 300×400 мм — 4 шт, 500×250 мм — 3 шт, 200×200 мм — 5 шт).

Строит карту раскроя — визуально показывает, как детали размещаются на листе.

Считает результат: сколько листов нужно, сколько всего деталей, площадь деталей и площадь листов, процент использования материала (в примере — 52,8%) и длину реза (в примере — 11,30 м).

Есть печать / PDF — результат можно распечатать или сохранить, что удобно для цеха.

По сути это инструмент для тех, кто работает с листовым металлом (лазерная резка, гибка, сварка конструкций): он помогает спланировать раскрой, оценить расход материала и подготовить карту раскроя для работы.
